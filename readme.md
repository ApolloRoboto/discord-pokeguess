# PokeGuess

Who’s That Pokemon!

Recreate the most nostalgic guessing game into your server. You can also create your own!

[Invite link](https://discord.com/api/oauth2/authorize?client_id=1052405591680757961&permissions=2147518464&scope=bot)

Find it on [Top.gg](https://top.gg/bot/1052405591680757961)

# Getting started

Initialize the repository:
```bash
just init
```

# Running the bot

Make sure to populate the `.env` file with your api tokens, and you should be ready to run the bot.
```bash
just run
```

## With Docker

```bash
docker-compose build
docker-compose --env-file ./.env up
```
