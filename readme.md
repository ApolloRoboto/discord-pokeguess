# Getting started

Initialize the repository:
```bash
just init
```

# Running the bot

Make sure to populate the `.env` file with your api tokens, and you should be ready to run the bot.
```bash
just run
```

## With Docker

```bash
docker-compose build
docker-compose --env-file ./.env up
```
